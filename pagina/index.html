FlowLibre

Manten un atajo, habla, y el texto aparece donde tengas el cursor. La transcripcion corre en tu maquina.

Descargar para Windows

Descargar para macOS Todavia no disponible — la version de Mac esta en camino.

Instalador de ~71 MB. Windows 10 u 11. Tambien hay version para macOS.

Windows va a decir "Windows protegio tu PC". Es normal.

FlowLibre no esta firmado con un certificado de codigo (cuestan varios cientos de dolares al ano). SmartScreen avisa de todo lo que no reconoce, no de algo que haya encontrado malo.

  1. Haz clic en Mas informacion.
  2. Haz clic en Ejecutar de todas formas.

Que pasa despues de instalar

  • Se abre un asistente de cuatro pasos: el atajo, la limpieza de texto (opcional), el microfono y la descarga del modelo.
  • Si tienes una GPU NVIDIA, baja el paquete de aceleracion. Si se corta, retoma donde se quedo.
  • Sin GPU tambien funciona: usa un modelo mas ligero en el procesador.
  • FlowLibre vive en la bandeja del sistema. Desde ahi se abre el panel y se sale.

Tus datos

La transcripcion es local: el audio no sale de tu maquina. El historial de dictados vive en %APPDATA%\FlowLibre y el desinstalador no lo borra — te pregunta.

La limpieza del texto es opcional. Si la activas con tu API key de Anthropic, el texto transcrito (nunca el audio) se manda a esa API para pulirlo. Sin key, FlowLibre escribe lo que dictas tal cual.
